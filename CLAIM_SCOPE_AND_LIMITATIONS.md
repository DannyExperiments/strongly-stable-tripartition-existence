# Scope and limitations

The input consists of finite nonempty sets of explicit propositional formulas. A preferred merge is inclusion-maximal and consistent in every priority prefix. The three induced source classes record whether every, some but fewer than all, or none of a source's formulas is individually consistent with the merge.

The reduction uses pairwise disjoint sources of at most three individually satisfiable formulas. It can produce a source whose formulas are inconsistent together. The hardness applies when empty ranking classes are allowed and when all three are required to be nonempty. Complexity is under polynomial-time many-one reductions.

The result concerns strong stability, with the ranking recovered by every preferred merge. Weak stability, restrictions to special logical languages, and simultaneous satisfiability within every source are outside its claimed scope. The companion skeptical-consequence problem uses the same base construction. [Companion record](https://doi.org/10.5281/zenodo.24572374)

The replay checks finite instances. The manuscript proves the complexity classification.
