# Release checklist

1. Confirm the intended tree and technical credits. Read the scope and the primary-source comparison.
2. Confirm repository integrity, exact replay and PDF rebuild on the actual commit.
3. Confirm that the README renders the figure and that the offline explorer archive opens.
4. Match the release tag and Zenodo version to the PDF, TeX source, bibliography, citation file, evidence ZIP and repository checksum ledger.
5. Confirm that public files, correct workflow badges and the version DOI resolve after publication.
